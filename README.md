# Mini Chocolate Chip Cookies Recipe Webpage

A responsive, single-page web application displaying a structured cooking recipe for mini chocolate chip cookies. This project was built from scratch to establish a foundation in local development, semantic markup, and cloud deployment pipelines.

## 🛠️ Key Implementation Details
* **Semantic HTML5 Structure:** Used meaningful tags (`<h1>`, `<h2>`, `<ul>`, `<ol>`) to properly separate the summary, ingredient lists, and sequential baking instructions.
* **Local Workflow:** Developed locally using Visual Studio Code and tracked changes with Git.
* **Production Deployment:** Configured a continuous deployment pipeline using GitHub Pages to host the static site live.

## 💻 Tech Stack
* **Frontend:** HTML5
* **Deployment:** GitHub Pages
